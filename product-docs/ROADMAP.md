# Steel Configurator Product Roadmap

## V1 — Perforated sheet configurator (included)

- Parametric sheet size and thickness
- Carbon / 304 / 316 material selection
- Round staggered, round straight, square, slot and hex perforations
- Hole size, pitch, border and slot-length controls
- Mill, galvanized, brushed and powder-coated finishes
- RAL color selection
- Live 3D, share/save, technical PDF, RFQ and AR foundation
- Live open-area, mass and hole-count estimates
- DXF flat-pattern export and CSV specification export

## V2 — Manufacturing intelligence

- Rule engine for minimum ligament, hole-to-edge distance and tooling limits
- Standard stock sheet sizes and yield / nesting feedback
- Grain direction and brushed-finish direction
- Tolerance classes and manufacturing notes
- Custom mounting holes, corner radii, notches and service cut-outs
- Quantity breaks, material price tables, perforation cost, finishing cost and delivery estimate
- Production-approved DXF / STEP generation service
- CNC / CAM job package and QR-coded traveler

## V3 — Fabricated architectural panels

- Folded return edges, cassette panels and configurable bend radii
- Z/G/hat stiffeners and rear-frame systems
- Stand-off brackets, clips, bolts and fixing patterns
- Panel joints, shadow gaps and expansion gaps
- Perforated screens, facade panels, ceiling panels, railing infills and machine guards
- Multi-panel wall/facade designer with automatic panelization
- Pattern continuation across adjacent panels
- Custom logos, images or vector artwork converted to perforation fields

## V4 — Manufacturer commerce / sales platform

- User accounts, project baskets and saved projects
- Multiple panel marks per project (P-001, P-002...)
- BOM / cutting list / finish schedule export
- Automatic RFQ and approval workflow
- CRM lead routing and sales dashboard
- ERP/PIM stock, material, finish and pricing integration
- Customer-specific price lists and distributor accounts
- Shopify / WooCommerce / custom website integration

## V5 — AEC / BIM / XR

- Revit family generation with dimensions, material and perforation metadata
- IFC / STEP / SAT handoff
- Revit/ACC project schedule export
- BIM object library and specification data
- AR full-scale panel review on walls/facades
- VR design review / showroom
- Configurator API and embeddable white-label SDK
